# 装备强化流程与判定规则

规则版本：2026-11-12-r8（红装+12节点副速度达到12速，继续强化到+15）。本文件是强化规则的统一维护文档；与历史讨论、旧版流程说明冲突时，以这里记录的最新用户确认规则为准。

维护约定：每次调整强化、保留、上锁或淘汰规则，都同步修改本文件的对应章节和更新记录，再同步代码、界面说明与相关回归。旧测试结果不能证明新规则通过；实机验证与离线验证分别记录在 `live-full-validation-2026-11-11.md`。

## 1. 整体循环

1. 主页右上角菜单进入钢铁工坊，选择打造来源和部件；次数默认十连，也可选单件。
2. 持续重新制作至装备背包满。金币不作强化前置余额识别；材料耗尽、游戏提示不足时停止。
3. 打开背包管理，先按游戏内已有整理预设快速选择；初次清理默认萃取，可选出售。
4. 按最大强化升序回到列表顶部，依次选择可强化装备，满16件即进入批量强化；不足16件须确认扫描到末尾。
5. 背包选装不逐件读属性，主副属性在批量强化页读取。已锁但未满级的装备同样可按规则强化，不自动解锁出售。
6. 每个强化节点重新判断，取消不再投入的装备勾选；有价值成品上锁，明确淘汰装备在本批结束后统一出售。
7. 强化后的淘汰装备只出售，不萃取；包含不能被快速选择选中的淘汰成品，需补选并核对名单。
8. 继续下一批，直到完整扫描确认没有剩余候选，再开始下一轮打造。

当前默认操作间隔0.2秒，可调整速度；仍等待游戏动画和结果稳定，不重复发送结果未知的资源确认。

## 2. 基础记录

- 初始未强化装备：三条副属性为紫装，四条为红装。紫装+12新增第四条后仍按紫装处理。
- 中途加入的装备，不能仅凭四条副属性反推红紫；使用已登记品质或标题核对。强化加成的异界传说属于红装。
- 强化触发节点为+3、+6、+9、+12、+15。经验溢出到+4/+7/+10等，仍按跨过的节点记录，不能额外多算一次。
- 速度只统计副属性；速度主属性鞋按主属性用途规则处理，不能把主属性增长算成副速度强化成功。
- 记录每档前后副速度、是否加速、红装累计未加速次数；断点恢复沿用同件装备的历史。
- 未识别、历史不完整不等于零；无法还原时不凭当前速度猜测强化命中次数。
- 紫装成品+15、副速度不超过12（含10/11/12速）明确淘汰，不以其他词条分数兜底。本批结束统一出售，遵守出售开关；已锁装备不自动解锁。紫鞋仍按原不投入、不自动处置规则。13～15速不因本次修改自动扩大淘汰范围。
- 此规则用于进入批量页的成品判断；背包选装仍跳过+15。本次不自动扫描或出售背包内已有成品。

## 3. 红装：速度优先，+12十二速继续，其余按累计未加速和有效分判断

### 3.1 计数口径

“未加速次数”指强化命中其他副属性的累计次数，**不要求连续**。一次涨2速或4速均只算一次命中速度。

例如，“速度→其他→速度→其他”在+12时累计两次未加速，此时转通用算分；不能因为+9曾加速就无条件继续到+15。

新装备逐档+3、+6读取结果，以便分清前两次分别强化了什么。所谓“带速先到+6”是前两档不因一次未加速直接止损，不是跳过+3历史记录。

### 3.2 带速度红装的阶段流程

| 当前阶段 | 决策 |
|---|---|
| 初始 | 通过主属性用途限制后，进入+3，再进入+6 |
| +3 | 记录第一档是否加速；即使未加速，也继续到+6 |
| +6 | 前两次至少一次加速，即未加速累计不足2次，继续+9；两次都未加速，转通用算分 |
| +9 | 累计未加速不足2次，继续竞速到+12；达到2次，转该阶段通用算分 |
| +12 | 副速度达到12速（含）直接继续到+15，不受累计未加速次数或有效分门槛限制；低于12速时，不足2次未加速继续，否则转通用算分 |
| +15 | 按实际副速度及有效分判断保留、上锁或淘汰，不再强化 |

**第二次未加速出现在哪一档，就在哪一档转通用算分；+12副速度达到12速是例外。** +9第一次没加速时仍可继续竞速；+9加速但此前已经累计两次未加速时，也不能恢复为纯竞速路线。到达+12（包括经验溢出的+13/+14）且副速度达到12速时，无论已记录几次未加速或历史未知，都继续+15。识别可靠及主属性用途限制仍生效，不因本条扩大允许主属性；+15成品保留和上锁门槛不变。

除+12十二速节点例外外，通用算分通过才继续下一档；不通过且具备明确淘汰依据时停止并列入统一出售。转入通用路线后，后续仍按各阶段有效分重新判断；到+12时达到12速则按新节点规则继续+15。

若当前副速度已经达到成品速度保留线，应保护其已有价值，不因低有效分判废。

### 3.3 典型链路

“速”表示该次强化增加副速度，“非速”表示强化其他副属性。

| 强化结果顺序 | 判断 |
|---|---|
| +3非速、+6速、+9速 | 累计1次未加速，继续竞速 |
| +3速、+6速、+9非速 | 累计1次未加速，仍可继续竞速，不因+9单次未加速直接止损 |
| +3非速、+6速、+9非速 | 累计2次未加速，在+9转通用算分 |
| +3非速、+6速、+9速、+12非速 | 累计2次未加速；当前副速度达到12则继续+15，不足12才转通用算分 |
| +3非速、+6非速 | 在+6转通用算分 |

用户给出的取舍依据：初始4速，若仅三次强化加速且每次都+4，成品才到16速；任一数值较低，就更难达到高速度目标。因此累计两次未加速后，不再只为竞速投入，要看其他属性的实际价值。这里是策略示例，不把它表述成已核验的概率或强化数值上限。

### 3.4 红装成品速度保留

- 以未重铸实际副速度14～16以上作为可保留范围，当前默认下限14，可在界面设为14、15或16。
- 达到配置速度线保留并上锁。20速仍是优先追求目标，不作为所有装备统一淘汰线。
- 实际速度不足时仍可由有效分路线保留；不把低速度直接等同于废装。
- 不凭速度直接猜重铸增量，不自动重铸。游戏实际或预览给出的重铸速度可单独记录。

### 3.5 无速度红装

从初始阶段按通用有效分判断；不享受“带速先到+6”的投入规则。速度不佳但其他有效属性高的红装，也走同一算分路线。

## 4. 通用算分：当前采用同用途有效加权分

本节是已获用户同意的助手自定义用途规则，不声称是官方规则或攻略原文。“通用算分”沿用这套规则，不自动改为全部词条总分，也不使用游戏内综合分数替代。

### 4.1 权重

| 副属性 | 加权值 |
|---|---:|
| 速度 | 数值×2 |
| 暴击率 | 数值×1.5 |
| 暴击伤害 | 数值×1.125 |
| 攻击%、生命%、防御%、命中%、抗性% | 数值×1 |
| 固定攻击 | 数值×3.46÷39 |
| 固定防御 | 数值×4.99÷31 |
| 固定生命 | 数值×3.09÷174 |

主属性不计入副属性分。游戏分数与助手加权分分别记录。

### 4.2 同用途有效属性

| 用途 | 计入的属性 |
|---|---|
| 攻击输出 | 攻击、生命、防御、暴击、暴伤、速度 |
| 慢速攻击输出 | 攻击、生命、防御、暴击、暴伤 |
| 生命输出 | 生命、防御、暴击、暴伤 |
| 防御输出 | 防御、生命、暴击、暴伤 |
| 抗性生存 | 生命、防御、抗性 |
| 辅助功能 | 生命、防御、命中、速度 |

攻击/生命/防御中的固定副属性按上表系数换算后，计入对应的用途。各模板分别计分，采用通过门槛的用途；仍要求至少三条副属性对该用途有效。生命、防御百分比均计入输出用途，权重各1；新增防御用途后，固定防御也按既有换算参与对应用途。速度优先、紫装仅速度和各阶段门槛不变。该模板为用户定制筛选，并不表示所有输出角色的防御收益都相同。

### 4.3 阶段门槛与加权上锁

| 强化阶段 | 左三件有效分 | 右三件有效分 |
|---|---:|---:|
| 初始 | 22 | 20 |
| +3 | 28 | 26 |
| +6 | 38 | 36 |
| +9 | 44 | 42 |
| +12 | 50 | 48 |
| +15保留线 | 56 | 54 |
| +15加权自动上锁线 | 59 | 57 |

左三件为武器、头盔、铠甲；右三件为项链、戒指、鞋。本表为当前用户配置：相对r5初始/+3提高2分，+6起提高4分，优先减少低速且有效属性不足的投入。速度竞速路线及集中属性保留路线不变。程序内置默认仍保留原值；当前工作区已保存本表门槛，点击“恢复默认”会恢复原宽松值。

加权自动上锁比成品保留线默认高3分，可配置。达到保留线但不足上锁线时暂存，不出售。速度达标上锁独立于加权门槛；单条非速度百分比达到25的集中属性保留路线继续适用。

## 5. 紫装：仅看副速度

- 紫装鞋子不强化；此条本身不新增自动出售授权。
- 紫装项链、戒指不看主属性，只看副速度；不用红装加权分兜底。
- 无副速度、初始副速度低于2，不投入；明确淘汰的未锁装备可按授权统一出售。
- 首档+3，每档未加速就停止强化；+12新增第四副词条是例外，不以该档未加速单独判废。
- +6～+8低于8速停止；+9起低于12速且没有已确认保留依据时停止。
- +12仍需通过速度线，不能用“新增词条”绕过速度要求。
- +15按成品速度保留规则处理，不能套用红装新设的未重铸14速线。原速度可选保留线16、优先线20保持不变；可信重铸速度可单独作为依据。
- 强化途中淘汰统一出售，沿用用户明确选择，不改成萃取。

## 6. 右三件主属性

红装默认允许：鞋子速度、攻击%、生命%、防御%；戒指攻击%、生命%、防御%、命中、抗性；项链暴击、暴伤、攻击%、生命%、防御%。助手提供自选主词条。速度主属性鞋优先考虑，仍按有效副属性判断质量。

固定攻击/生命/防御主属性的右三件：带副速度保留追速例外，无副速度不强化，可按初次清理配置出售/萃取；已强化后淘汰仍统一出售。紫装遵循上一节独立规则。

## 7. 保留、上锁与出售

- 速度达标或达到加权上锁线等明确价值条件：保留并确认上锁。
- 达到加权保留线但未到上锁线：暂存，不出售。
- 无法确定用途、历史缺失或识别不可靠：暂存或只读重试，不按缺失值判废。
- 已锁装备不自动解锁出售。
- 退出竞速不等于淘汰，必须先经过对应阶段的通用算分；不合格才进入明确淘汰名单。
- 批次结束核对明确淘汰集合及保留集合，再统一出售，并确认背包减量、保留装备与锁状态。

## 8. 自定义搭配计分（可选，仅红装）

- 默认关闭；保存组合不等于启用。勾选“启用自定义计分”并保存后，仅影响下一次开始的任务，不改变已运行任务的策略快照。
- 支持最多32组命名搭配。每组可选多个套装（任选其一，留空表示任意套装）和1～4条副词条（必须同时具有，允许有额外副词条）；不同组任一命中即可。同一装备命中多组不会叠加分数。
- 命中红装后，用**全部副词条加权总分**代替同用途有效分，不再要求至少三条属于同一用途。百分比权重、速度×2、暴击×1.5、暴伤×1.125及固定副词条换算均沿用4.1节；游戏综合分、主属性和套装加成不计入此分。
- 可分别设置左/右三件的初始、+3、+6、+9、+12、+15门槛。初始显示当前红装门槛；每侧六档全部留空时动态沿用普通红装门槛。门槛必须为非负有限数且随阶段不下降。
- **保持速度优先**：带速红装先逐档至+6，后续按累计未加速记录竞速；+12达到12速直接继续+15，副词条符合自定义组合但套装暂未识别时也不拦截这一速度路线。其余退出竞速的装备以自定义总分兜底。主属性限制、已锁不出售、读取失败不盲点等仍生效。+15总分达保留线暂存，达到保留线＋现有上锁增量时上锁；已有速度和集中属性保留路线不变。
- 用户确认紫装仍按原规则，包括紫鞋不强化，不使用自定义总分。未命中组合的红装仍按普通规则。
- 套装仅在功能启用且有指定套装时，于批量强化入口以图标模板识别，不增加全屏文字OCR。副词条组合满足但套装读不准时暂存，不据此出售。界面显示最近命中、当前总分及决定，逐档命中记录写入本次任务日志。
- 作用范围是进入批量强化页后的装备；游戏预设“初次整理/快速选择”仍在此前执行，自定义组合不会撤销已经执行的初次萃取或出售。
