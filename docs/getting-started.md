# 新手指南

## 准备与连接

按首页安装Python依赖，在MuMu打开第七史诗国服。设置游戏渲染分辨率为1280×720；桌面窗口大小不等于ADB截图尺寸。界面需要WebView2，部分截图诊断需要Windows中文、英文OCR语言支持。

从MuMu设置/诊断查看实际ADB端口，使用MuMu安装目录中的adb.exe。多开必须选定正确实例，不要照抄别人的端口。

```powershell
# 替换尖括号中的内容
.\.venv\Scripts\python.exe -m e7_assistant adb --executable '<adb.exe完整路径>' devices
.\.venv\Scripts\python.exe -m e7_assistant adb --executable '<adb.exe完整路径>' connect '<实例地址:端口>'
```

在助手设置中填写ADB路径与实际设备号，先连接。授权未通过或状态不是device时，先处理模拟器连接。

## 任务

| 任务 | 场景 |
|---|---|
| 打造并强化 | 普通打造到满包，整理并逐批强化，再进行下一轮 |
| 仅强化背包 | 处理已有装备，不先打造 |
| 传说定向制作 | 中央锻造器选择套装、部位，件数留空按剩余次数继续 |

首次请限制操作次数，观察小规模结果。**初次整理使用游戏已有快速选择预设**，先手动核对会选中什么。强化会实际消耗粉末、强化石等资源，出售不能撤回。

## 设置与预设

设置中调整速度、右三件主属性、红装门槛以及套装＋词条组合。组合默认关闭，仅用于红装；紫装仍遵循追速规则，紫鞋不强化。具体见[规则](enhancement-rules.md)。

个人设置和组合保存于本机config/ui.json，备份在config/backups/。更新时保留这些文件；公开仓库不会提供作者个人配置。

## 接管与恢复

运行中避免手动切换游戏或同时执行其他自动操作。接管前先暂停/停止，等待当前操作退出。暂时拒识会只读重试，仍无法确认消费结果时保留回执；再次开始或恢复入口会核对证据。不要直接删除待核验文件强行重试。

日志与截图在本机runs目录，不随源码公开。反馈前裁剪截图并隐藏账号信息。
