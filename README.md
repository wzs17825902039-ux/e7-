# 第七史诗国服 · 打铁助手

面向 **Windows + MuMu** 的装备打造与强化助手，使用 React / WebView2 桌面界面，通过 ADB 截图、RapidOCR 和 OpenCV 识别游戏画面。

> 开发联调版。自动操作会消耗游戏资源，并可能出售装备；请先阅读规则、小规模试用。非官方项目，自动化可能违反游戏服务条款，无法保证账号安全。

## 功能

- 普通装备持续打造至背包满，选择来源、部位和单次/十连。
- 中央锻造器传说定向制作，选择套装与部位。
- 背包批量强化，按节点判断红紫装，保留并上锁有价值装备。
- 红装速度优先、有效加权分兜底；支持自定义「套装＋指定副词条」。
- 初次整理使用游戏已有预设，强化后的明确淘汰装备统一出售；不自动解锁出售。
- 速度成果统计、操作速度调整、暂停/停止、识别重试和回执恢复。

规则以[统一强化规则](docs/enhancement-rules.md)为准。游戏综合分与加权有效分是不同口径。

## 安装与启动

**普通用户优先下载 [Windows 预发行版 v0.3.0-beta.1](https://github.com/wzs17825902039-ux/e7-/releases/tag/v0.3.0-beta.1)**：在 Assets 中下载 EXE，放入独立可写文件夹后双击，无需安装Python。中文说明与SHA256校验文件一并提供。更新前关闭助手，保留原来的配置与运行记录。

源码仓库不提交EXE；发行附件也不包含MuMu、ADB工具包或个人配置。仍需MuMu、实际ADB及WebView2 Runtime。开发者可按下面步骤源码运行。

需要 Windows、Python 3.11+、MuMu中的国服游戏以及 Microsoft Edge WebView2 Runtime。截图分辨率需为 **1280×720**。建议 Python 3.11，其他版本的OCR依赖兼容性请另行核实。

```powershell
git clone https://github.com/wzs17825902039-ux/e7-.git
cd e7-
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[ocr,desktop]'
.\.venv\Scripts\python.exe -X utf8 客户端.py
```

仓库包含编译后的前端资源。首次OCR初始化可能下载模型，需要网络。修改前端或打包EXE另需Node.js 22.12+与npm，见[开发指南](docs/development.md)。

打开助手→填写MuMu的ADB路径和实际设备号→连接→选择任务与参数→开始。初次使用请限制操作次数，先检查游戏内快速选择预设，在旁观察。

## 兼容性与验证边界

仅针对国服既有页面和1280×720布局适配，其他服务器、分辨率及后续游戏更新未保证兼容。OCR可能拒识或误识别，不承诺永不中断；结果未知时保留记录，避免重复消费。不注入游戏、不修改游戏内存，不提供绕过检测功能。

项目包含离线回归和EXE检查代码，但部分用例依赖开发机历史截图。公开仓库不附账号截图与运行日志，因此全量测试不保证开箱即过。当前版本连续游戏消费及提速计时仍需实机验收。
